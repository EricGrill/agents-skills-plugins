# Standalone native skills

This directory contains complete directory-form skill packages for native agent discovery, separate from the Claude plugin catalog under `plugins/`. Skills remain opt-in; install or load the whole package rather than injecting only its `SKILL.md`.

- `picoclaw-fleet/`: PicoClaw worker-fleet orchestration; see its [README](picoclaw-fleet/README.md).
- `diagram-design/`: 45 diagram types with companion references, templates, assets, and accessibility/geometry helpers; see [Seven's native Linear installation and loading guide](diagram-design/SEVEN.md) and [immutable upstream attribution](diagram-design/UPSTREAM.md).
